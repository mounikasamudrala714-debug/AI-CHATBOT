# AI Chatbot

This is a simple AI chatbot project created for an internship. The chatbot runs in a web browser and gives predefined replies based on the user's message.

## Project Description

The AI Chatbot is a basic web application developed using Python Flask for the backend and HTML, CSS, and JavaScript for the frontend.

The chatbot takes input from the user, processes the message, checks for specific keywords, and displays a suitable response in the browser.

## Features

- Simple chatbot interface
- Runs in a web browser
- Python Flask backend
- HTML and CSS frontend
- JavaScript for sending messages
- Predefined chatbot responses
- Suitable for beginner-level internship project

## Technologies Used

- Python
- Flask
- HTML
- CSS
- JavaScript
